# Planning Backlog

Record deferred plans here when they are useful but not active. Each backlog entry should include a short problem statement, likely owner repository, related repositories, expected trigger for activation, and any known stop conditions.

Do not start backlog work just because it is listed. Move it to `ACTIVE.md` when a user request or project decision makes it current.

The LGSL/GameQ/protocol-removal plan is active in this repository and is tracked in `ACTIVE.md`.

The global port allocation plan is active in this repository and is tracked in `ACTIVE.md`. Deferred implementation phases must point back to `docs/plans/global-port-allocation/PLAN.md` rather than creating a separate port-planning convention.
